# Test Model Viewer
A simple Unity project for viewing and interacting with a 3D model. This project is an example of how it can be used.

## Controls

Mouse - pan around the building in an orbit around its center

W and S or Up and Down arrows - tilt orbit center up or down

A and D or Left and Right arrows - cycle between viewable models

Mouse wheel - Zoom in or out

Tab - open settings menu

Space - pause or unpause animations

All of the above controls can additionally be accessed by opening the menu (the 3 bars in the corner).
